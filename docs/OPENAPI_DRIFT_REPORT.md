# OpenAPI drift report

Initial report for #601, generated by `npm run check:openapi-drift -- --report`. The check (`scripts/check-openapi-drift.js`) compares routes mounted under `/api/v1` in `src/index.ts` with `docs/openapi.yaml`, and runs in the `API contract` CI job.

Known drift is frozen in [openapi-drift-baseline.json](./openapi-drift-baseline.json). CI fails on any **new** drift, and on baseline entries that have since been fixed. Backfill a route, then run `node scripts/check-openapi-drift.js --update` to shrink the baseline.

Backfilled so far: the `/admin/erasure/requests*` and `/admin/erasure/preview` routes.
